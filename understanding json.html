Understanding JSON in JavaScript

JSON stands for JavaScript Object Notation. It is a lightweight format used to store and exchange data. Although it originated from JavaScript, JSON is supported by almost every programming language.

Why Do We Use JSON?

  • Store data in Local Storage.
  • Send data between a web browser and a server.
  • Read configuration files.
  • Exchange data between different programming languages.

JavaScript Object

const student = {
    name: "John",
    age: 22,
    course: "Computer Science"
};

Equivalent JSON

{
    "name": "John",
    "age": 22,
    "course": "Computer Science"
}
Notice:
  • JSON keys must always use double quotes (" ").
  • Strings use double quotes.
  • JSON cannot contain functions.
  • JSON cannot contain undefined values.

JavaScript Object vs JSON

JavaScript Object JSON
Can contain functions Cannot contain functions
Keys may use quotes or not Keys must use double quotes
Used inside JavaScript programs Used for storing and transferring data
Actual object Text (String)

Converting an Object to JSON

Use JSON.stringify(). 

const person = {
    name: "Alice",
    age: 25
};

const jsonString = JSON.stringify(person);

Converting JSON Back into an Object

Use JSON.parse(). 

const json =
'{"name":"Alice","age":25}';

const object = JSON.parse(json);

JSON and Local Storage

Local Storage only stores strings. If you want to save an object, convert it into JSON first. 

// Save
localStorage.setItem(
    "student",
    JSON.stringify(student)
);

// Read
const data =
JSON.parse(localStorage.getItem("student"));

Summary

  • JSON stands for JavaScript Object Notation.
  • JSON is a text format used to store and transfer data.
  • JSON.stringify() converts an object into a JSON string.
  • JSON.parse() converts a JSON string back into a JavaScript object.
  • JSON is commonly used with APIs and Local Storage.
